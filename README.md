# CodeAlpha Tasks

This repository contains the Android apps I built as part of my **CodeAlpha Internship**.

## Projects

### 1. Random Quote Generator
A simple Android app that displays a new random quote every time the user taps the button.
- **File:** `random.apk`

### 2. Flashcard App
An Android app for creating and revising flashcards, designed to make studying easier.
- **File:** `Flashcard.apk`

## How to Install
1. Download the `.apk` file from this repository.
2. Open it on your Android phone.
3. If asked, allow **Install from unknown sources**.
4. Install the app and open it.

## Tech Stack
- Android (Java/Kotlin)
- Android Studio
